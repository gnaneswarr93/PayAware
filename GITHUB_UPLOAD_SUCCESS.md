```bash

# Frontend setup
cd project

npm run dev

# Backend setup

python -m venv venv
.\venv\Scripts\activate  # Windows
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### For Future Updates:

When you make changes:
```bash
cd c:\Users\user\Downloads\Payaware

# Check what changed
git status

# Add all changes
git add .

# Commit with message
git commit -m "✨ Add new feature"

# Push to GitHub
git push origin main
```

### Create `.env.example` Template:

So team members know what environment variables they need:
```bash
# Create template file
echo "VITE_SUPABASE_URL=your_supabase_url_here" > project/.env.example
echo "VITE_SUPABASE_ANON_KEY=your_supabase_key_here" >> project/.env.example

# Commit it
git add project/.env.example
git commit -m "📝 Add environment variable template"
git push origin main
```
